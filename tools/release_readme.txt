Q3Remaster (Windows, 64-bit)
============================

A non-commercial fan remaster of Quake III Arena. It is not made, endorsed or supported by
id Software, Bethesda or Microsoft. You need your own copy of Quake III Arena to play.

OPEN BETA: SINGLE PLAYER ONLY. You can play the campaign and offline matches against bots.
Friends, parties and leaderboards are online, but you can't play matches against other
people yet. Online multiplayer is planned; see the project page below for what's coming.

Installing
----------
1. Unzip this folder anywhere.
2. Put textures-1.pck and textures-2.pck (separate downloads on the same release page)
   in this folder, next to Q3Remaster.exe.
3. Run Q3Remaster.exe.

On the first launch the game asks for your Quake III Arena: drag your pak0.pk3 (from the game's
baseq3 folder, Steam or GOG or CD) onto the window, or use Browse. That is the only file it needs.
Nothing is copied; the game remembers where it is and checks it on every launch.

Q3Remaster.console.exe is the same game with a console window showing its log, for bug reports.

Source code and issues: https://github.com/ozmiumofficial/quake-3-arena-remastered-fan-project
