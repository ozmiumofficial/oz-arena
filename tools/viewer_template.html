Workflow

How this version was made

Every step is a script you can rerun, so the pipeline works for any id Tech 3 player model, including this one.

  1. Extract

    A .pk3 is a zip. models/players/{{MODEL}}/ holds three MD3 meshes (legs, torso, head) joined at tag points, an animation.cfg with the frame ranges, and the painted TGAs.

    pak0.pk3 → 28 files

  2. Weld and smooth

    MD3 duplicates every vertex along a UV seam. Merging duplicates that match in all frames gives a clean cage. Two levels of Loop subdivision round it off, and edges sharper than 50° stay creased so the armor keeps its hard lines.

  3. Recover the skeleton

    MD3 stores no bones, only vertex positions per frame. Skinning decomposition finds the rigid bone motions and per-vertex weights that best rebuild every frame, then places each joint where neighboring bones agree. Legs and torso are fitted separately so they still animate independently, as they did in the game.

  4. Assemble the rig

    Blender merges the pieces into one mesh, carries the weights through the subdivision, and writes one action per animation.cfg entry. Leg clips key only leg bones and torso clips only torso bones, so any pair layers cleanly. Try Run with Attack above.

    .blend · .fbx · .glb

  5. Build PBR maps from the painting

    The UV islands are padded so seams don't bleed, then upscaled 8× with edge-preserving cleanup. Each texel is sorted by color into a material class. The painted light and shadow move out of the albedo into ambient occlusion. Height comes from luminance and the class relief, and normals and curvature follow from it. Edge wear, scratches and grunge are added on top.

  6. Bring it into Unity

    Import the FBX as a Generic rig with two avatar masks (legs, torso) on separate Animator layers, the same split the game used. In URP Lit, metallic and smoothness share one texture, so the AO/rough/metal map is repacked as metal in red and smoothness (1 − roughness) in alpha.

What this pass can't do

Limits of an automated remaster

  • Detail: upscaling invents nothing. The 2048² maps are sharper and properly lit, but every shape still comes from the original painted pixels.
  • Form: subdivision only rounds the 1999 shapes. Plates get softer, not more detailed.
  • Bending: the original topology has no edge loops at elbows or knees, so joints bend stiffly. The rig reproduces the old animation well (about 6 mm average error) but it isn't built for new motion yet.
  • Materials: the classes come from color alone, so a few rust-orange plate accents and dark recesses are still guessed.
Production path

What a full remaster adds

  • Sculpt a high-poly {{TITLE}} over this silhouette (ZBrush or Blender), using the remaster as the proportion and pose reference.
  • Retopologize to a 20–40k triangle game mesh with loops at the joints, then bake normal, AO and curvature from the sculpt.
  • Texture in Substance Painter, with these class masks as the starting ID map.
  • Map the skeleton to a Unity Humanoid avatar so modern animation libraries can drive it, keeping the recovered 1999 clips as reference.
  • Run an AI upscaler on the original painting to get reference detail for the repaint.
